# Testes de acessibilidade

Coloque nesta pasta verificações automatizadas de acessibilidade e cenários manuais por fluxo/tela. Registre navegador, viewport, tecnologia assistiva quando aplicável e limitações de cada execução.

Os resultados devem ficar em `tests/resultados/acessibilidade/`. Ainda não há uma ferramenta ou suíte de acessibilidade configurada.
